Taarikh Datepicker Playground

Accessible, zero-dependency Fatimid Hijri calendar datepicker component

Standard Picker

English labels, Fatimid Astronomical calendar, default formatting (YYYY-MM-DD).

RTL & Arabic Localisation

Arabic label pack, Eastern numerals, mirrored glyphs (‹/›), and mirrored arrow keys.

Min & Max Date Constraints

Restricted to 1445 AH Ramadan (1445-09-01) through Zilhajj (1445-12-30). Out-of-bounds dates are disabled and invalid inputs show aria-invalid="true".

  • WAI-ARIA APG Dialog Pattern Native <dialog> opened with showModal() into the top layer. Freely typeable input with an adjacent trigger button; input focus never auto-opens.
  • RTL & Logical Properties Layout mirrors automatically via CSS logical properties. Prev/next glyphs mirror and keyboard arrow keys mirror in RTL (Right arrow moves back, Left arrow moves forward).
  • Value Contract Preserved Submitted value remains strictly ASCII YYYY-MM-DD for seamless backend validation, while Intl localized digits and labels are used exclusively for display.
  • CSS Anchor Positioning Native anchor-name and position-anchor align the modal adjacent to the input with automatic flip-block/flip-inline fallbacks and centered modal fallback.
  • Zero Runtime Dependencies No jQuery, no React, no external date libraries. Vanilla TypeScript bundled to pure ESM and IIFE with complete .destroy() teardown safety.
  • Intl Formatting & Caching High-performance Intl.DateTimeFormat and Intl.NumberFormat caching with full user-overridable string dictionaries and accurate Arabic-script comma detection.
