Usage & Integration Guide

Everything you need to integrate the Taarikh Hijri Datepicker into your web application or form.

1. Required HTML Structure

The picker requires only a standard HTML <input> element with an accessible label. You do not need to write any <dialog>, button, or calendar table markup manually. 

<!-- Minimum Required HTML -->
<label for="hijri-date">Hijri Date</label>
<input type="text" id="hijri-date" name="hijri_date" placeholder="YYYY-MM-DD" autocomplete="off" />
  • Input Type: Use type="text". Standard type="date" inputs enforce Gregorian calendar dates and trigger browser-native pickers.
  • Accessible Labeling: Always pair the input with a <label for="..."> or specify aria-label / aria-labelledby for WCAG 2.2 AA compliance.
  • Automatic DOM Injection: The calendar trigger button (.tp-btn-trigger) and modal (.tp-dialog) are automatically generated and inserted as adjacent siblings (input.after(trigger, dialog)).
  • Text Direction (RTL): Add dir="rtl", dir="ltr", or dir="auto" to the input or any ancestor container (e.g. <form dir="rtl">). The picker automatically detects direction to mirror navigation glyphs and keyboard arrows.
  • Pre-filled Values: An optional value="YYYY-MM-DD" (ASCII numerals, e.g. value="1446-09-01") will be parsed and selected automatically on initialization.

2. Installation Options

Install via your package manager or directly via script tag:

npm (ESM / Bundler):

npm install @taarikh/picker
import { createPicker } from "@taarikh/picker";
import "@taarikh/picker/style.css";

const input = document.querySelector("#hijri-date");
const picker = createPicker(input);

Composer (Drupal Library / Packagist):

composer require hussainweb/taarikh-picker

Standalone IIFE (Direct <script> Tag):

<!-- Stylesheet -->
<link rel="stylesheet" href="/libraries/taarikh-picker/dist/style.css" />

<!-- Input -->
<label for="hijri-date">Hijri Date</label>
<input type="text" id="hijri-date" name="hijri_date" placeholder="YYYY-MM-DD" />

<!-- Standalone IIFE Script -->
<script src="/libraries/taarikh-picker/dist/index.iife.js"></script>
<script>
  const input = document.getElementById("hijri-date");
  const picker = TaarikhPicker.createPicker(input);
</script>

3. Key Configuration Options

Pass an optional options object to createPicker(input, options):

Option Type Default Description
locale string Browser default BCP 47 language tag (e.g. 'ar', 'fa', 'en').
dir 'ltr' | 'rtl' | 'auto' 'auto' Text direction. Automatically detects from ancestor [dir] or computed style.
minDate PlainDate undefined Earliest selectable date: { year, month, day }. Earlier dates are disabled.
maxDate PlainDate undefined Latest selectable date: { year, month, day }. Later dates are disabled.
initialDate PlainDate Today Default visible month and focused date when the input is empty.
valueFormat string 'YYYY-MM-DD' Date format pattern for submitted input value.
labels PickerLabels English/Fatimid Custom string overrides for buttons, header selects, dialog title, and live regions.
onSelect (date: PlainDate) => void undefined Callback fired when a date is selected.

4. Events & Form Value Contract

When a date is chosen, the picker dispatches native input, native change, and a custom taarikh:change event: 

input.addEventListener("taarikh:change", (event) => {
  const { date, value } = event.detail;
  // date: { year: 1446, month: 9, day: 1 } or null
  // value: "1446-09-01" or ""
  console.log("Selected Hijri Date:", date);
  console.log("Submitted ASCII value:", value);
});

Value Contract: Submitted form values are strictly zero-padded ASCII YYYY-MM-DD strings suitable for backend validation. Localized digits, script separators, and month names are used strictly for UI presentation.
